# TicketSwap-монітор — The National, Сан-Себастьян

## Що робить
Кожні 4-7 секунд перевіряє сторінку квитка. Щойно "Available" стає більше 0:
- гучне macOS-сповіщення зі звуком + голосове оголошення ("say")
- автоматично відкриває сторінку квитка у твоєму браузері за замовчуванням
- повторює сигнал кожні 6 секунд, поки ти не зупиниш скрипт або квитки знову не зникнуть

Це **не купує квиток автоматично** — зупиняється на "відкрив браузер на потрібній сторінці й репетує, доки ти не зайдеш". Чому не далі — дивись у чаті: Stripe-оплата й 3D-Secure реально неможливо обійти скриптом, і протестувати checkout не було на чому (зараз 0 квитків у продажу).

## Як запустити
Відкрий Термінал (Terminal.app) і виконай:

```
cd ~/Documents/ticketswap-bot
node monitor.js
```

Залиш це вікно Терміналу відкритим і Мак увімкненим — поки скрипт працює, він стежить.
Щоб зупинити — натисни Ctrl+C у Терміналі.

Лог усіх перевірок пишеться в `monitor.log` у тій самій папці — можна глянути, чи скрипт справді живий.

## Щоб не тримати Термінал відкритим вручну (опційно)
Якщо хочеш, щоб скрипт сам стартував і сам перезапускався, якщо впаде, можу налаштувати автозапуск через launchd (системний планувальник macOS) — просто скажи.

## Якщо захочеш зробити наступний крок (авто-чекаут)
Коли квиток реально з'явиться на цьому чи схожому концерті — скажи мені одразу, і я на льоту перехоплю справжні запити checkout-флоу TicketSwap і спробую довести автоматизацію до кнопки оплати (з урахуванням, що фінальне 3D-Secure підтвердження все одно прийде тобі на телефон від банку).
